# Simple Interest Calculator

This is Task 6 of Web Development with JavaScript course.

## Description
A simple calculator to calculate Simple Interest and Total Payable Amount.

## How to Run
1. Open index.html in browser
2. Enter Principal, Rate and Years
3. Click Compute button
